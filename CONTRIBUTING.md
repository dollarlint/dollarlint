# Contributing

Contributions are welcome through detailed issues. Pull requests are discouraged.

If you find a bug, have a feature request, or want to suggest a change, please open an issue with as much context as possible. Useful issues include:

- What you expected to happen
- What actually happened
- Steps to reproduce the behavior
- Relevant configuration, command output, sample files, or logs
- The version of `dollarlint` you are using
